# FableForge 0.18.0-rc.2

This is a prerelease of the editor and world-view update. Version 0.17.1 remains
the latest final release.

## Editor workflow

- Placed things have clearer selection and ownership controls. Ground placement,
  drag carry, keyboard nudges and rotations, multi-selection, owner-aware moves,
  safe duplication and deletion, creature links, and region entrance links have
  focused undo and retail-map checks. Meshless markers use distinct shapes,
  letters, hover labels and a viewport legend.
- Sculpting and direct height edits carry grounded placed things in the same undo
  step. Baked foliage follows the edited ground in the preview. Terrain and
  object positions still have separate game writes; the Terrain panel names both.
- Generate terrain and Fit to Neighbours describe their height range and report
  Fit's pending vertex count and largest height change. Fit preview, Apply, Undo
  and Redo were checked on Greatwood_Filler_04.
- Setup restores the backed-up bytes, reloads an open map, and keeps its actions
  reachable with a long backup list. Switching installs protects unsaved edits
  and clears the old map. The map browser, viewport and tool panel fit compact
  windows with full-label menus for controls that cannot fit inline.

## Assets, mods and world view

- Assets now includes model and effect browsers and a dialogue preview with
  retail lip-sync data, head poses, eye graphics and scratch export tools. The
  effect preview has background colours, a ground grid, transport controls,
  mesh/light inspection and selected-frame playback. Unsupported engine particle
  behaviours are still approximated by the editor.
- Mod packs now report missing asset references relative to retail data. Corpus
  checks cover representative Aeon Edition, Controller Support, Freeroam and
  content-pack paths where their local archives are available. These checks do
  not promise every install order is compatible.
- World flight continues to improve terrain, object and foliage loading,
  selection, memory use, transitions and cutout quality. The world view still
  reflects authored gaps between maps; it does not create terrain there.
- The README now leads with the 3D World view and links to a
  [feature gallery](../FEATURE_GALLERY.md) covering the 2D layout, terrain,
  assets, mods and setup.

## Validation and remaining limits

The 2026-09-30 release build passed all 70 `tools/check_all.py --no-build`
checks: CTest, eight retail map smokes, GUI workflows, scratch-install writes,
World flight, and the available mod corpus paths. The three README overview
screenshots, feature-gallery captures, model browser and light-background FX
preview were inspected from this build. Scratch-install checks do not write to
the user's game. Fresh-game probes and the separate-machine walkthrough remain
required before a final 0.18.0 release. Exact dialogue-eye attachment and some
world geometry, lighting and particle behaviours still need retail comparison.

The 28.4 MB Windows zip was extracted and smoke-tested: `forge list` found the
retail map list, `forge info Greatwood_1` read its terrain, `forge-tools wad
list` read FinalAlbion.wad, and the packaged GUI loaded Greatwood_1 through
automation. The README and feature-gallery local links resolve inside the zip.
