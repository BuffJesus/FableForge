This prerelease lets you see Fable's randomised villagers and bandits exactly as a seed builds them, and export models for Blender with their skeletons. Stable 0.18.0 and the earlier release candidates remain available.

- **Creature looks** (Assets > Models): pick a villager or bandit, type a Seed or press **New look**. FableForge assembles the textured head, torso and legs the game would choose, with its body shape (fat, tall, short, strong, weak). The selection follows the game's own code, verified against the original instructions; the preview is the bind pose, without animation. Guide: `guide/creature-looks.md`.
- **Export .glb (Blender)** for any model or creature look. Skinned models keep their own skeleton and weights, in metres, so an edited model re-imports against the same donor.
- **Fixed: imported models had vertically flipped textures.** Model import stored texture V inverted relative to the game, FableForge's preview and EgoCore. Exporting and re-importing retail meshes now reproduces their texture coordinates exactly. Models imported with earlier versions keep the flipped mapping until re-imported.
- Carries forward the definition/creature authoring, Unicode definition editing and skinned-import work since rc.2.

### Validation

All 62 local CTest targets pass, and Windows CI passes on the release head (24e817c). The attached archive (SHA256 `b40259144405cfdc37c2c502597a67a3553ad57ec89e292802cb3bab9d365d9a`) passes 124 file identities, 158 documentation links and all 57 selected extracted workflows (93 not run, 2 optional corpus skips). Twelve retail body meshes round-trip through rigged export and the real importer with identical triangles, positions, texture coordinates and weights. The Creature looks UI script passes against a retail install. An adversarial review of this work confirmed six defects; all are fixed in this release.

Known limitation: definition saves fail when a staged path reaches Windows' 260-character limit (install paths over about 200 characters). Default Steam paths are well below that.

Not yet checked in game: the texture-orientation fix on an imported model, and assembled creatures beyond the editor preview.
