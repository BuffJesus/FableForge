# FableForge 0.18.1-rc.2

This prerelease makes compiled definitions and dialogue text easier to browse and edit while preserving native references and recovery records. It continues the Aeon/controller preview from rc.1. Existing stable releases remain available.

- Definitions now have a searchable type/group tree, group/member navigation and links from confirmed fields to native models and terrain textures.
- Field drafts support scalar, boolean, vector, colour and bounded ASCII strings. Wide-string CLI writes accept UTF-8; valid wide values display as readable text. GUI Unicode authoring and broader font coverage remain unfinished.
- Name references display the owning names-pool entry and offer a searchable existing-name picker. Duplicate and unused names retain their byte offsets. Invalid changed references refuse to save.
- `forge-tools defs clone` copies an exact donor and publishes its bank/name-pool pair with rollback and Restore. GUI cloning remains unfinished.
- Text authoring includes speaker, metadata and tag controls, pack destinations, byte-safe exports and protection for open drafts during Close/Install.
- Carry-forward asset/parser work improves preservation, exact identity lookup, malformed-input refusal and scratch-install recovery. No game files or third-party mod data are bundled.

## Validation

The source milestone passed focused definition GUI, CLI and copied-retail checks. Name picking passed 26 GUI cases across both window sizes, with exact field deltas and Restore. Clone publication passed 35 cases, including rollback, physical aliases, running-owner/junction refusal and exact Restore. A full retail-bank export preserves all 14,764 existing records and identity rows and appends only the donor copy and its new name. Native game hashes remain unchanged. Previous local checkpoints retain their exact archive hashes and exercised workflows in the handoff.

The isolated RC2 build, full local CTest inventory, GitHub CI and extracted RC2 package are being validated. Their final results will be recorded before this candidate is published. A passing focused gate does not imply all available package workflows ran.

## Remaining release gates

Live gameplay for these changes, a clean-machine/VM walkthrough, broader GUI font coverage and the final in-game release probes remain unverified. This candidate is a prerelease on the way to 1.0; it is not the latest stable release. Use `forge restore` for tracked scratch/install changes.
