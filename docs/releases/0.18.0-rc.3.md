# FableForge 0.18.0-rc.3

This preview adds a redesigned Dialogue workspace, native Browse controls and an
illustrated Aeon Edition + Controller Support guide. It includes the editor,
world-view and asset-browser work from rc.2. Version 0.17.1 remains the latest
final release.

## Downloads

- **FableForge-0.18.0-rc.3-win64.zip**: extract it and run **FableForge.exe**.
  Open **AEON_CONTROLLER.html** beside the executable for the illustrated guide.
- **FableForge-Aeon-Controller-Guide.zip**: the same guide and four screenshots,
  packaged separately for sharing. Extract it and open **AEON_CONTROLLER.html**.
  This small ZIP does not contain the application or third-party mods.

## Changes since rc.2

- Dialogue has a visible line dropdown, immediate browsing and search across all
  dialogue banks by words, speaker, entry name or Sound ID. Character selection
  offers 18 retail previews, including additional villagers and the Oracle.
  Playback sits beside the preview; an optional timeline and separate edit/save
  window keep the main workflow clear. Compact layouts, staged edits, archive
  export and pack recipes have focused checks.
- Mod, model, texture, theme and dialogue-export path fields now include native
  Browse controls. Mod sources offer both file and folder selection; exports use
  Save As. Cancel preserves the previous path.
- The Aeon/controller walkthrough explains the FMP and DLL roles, Forge's file
  composition, EgoCore's runtime loading, and why this route needs no separate
  FreeRoam step. No game files or third-party mods are bundled.
- Mods now update the displayed winner immediately when a saved conflict choice
  is cleared. Invalid order, choices, missing sources, malformed pack manifests
  and missing recipe assets are rejected before replacing an existing deployment.
  Recipe failures return an error and refuse to stage an incomplete build.
- Additional scratch checks cover mod paths containing spaces and shell-special
  characters, dependency labels, recoverable imports, world-pack composition,
  terrain worker snapshots and new-level creation while edits are pending.

## Validation and remaining limits

Validation covers 35 core test suites, targeted retail GUI and scratch-install
workflows, Dialogue search/head-pose AddressSanitizer checks, and the extracted
Windows package. The full retail GUI suite was not rerun as one aggregate gate
for this candidate; focused checks and retained evidence are recorded in
`docs/HANDOFF_WORLD_UI.md` and `docs/FEATURE_DEPTH_AUDIT.md`.

Fresh-game release probes and the separate-machine walkthrough remain pending.
The Aeon/controller composition was checked against the supplied mod files, but
runtime operation on a Retroid Pocket 5 has not been tested. Later build failures
can still leave a previously deployed install at its restored baseline; deployment
replacement is not yet fully transactional. Read the included guide before using
the Aeon/controller recipe on a clean Steam Fable: The Lost Chapters installation.
