2560x1440 (s1.0, s0.8) and a 3840x2160 request (clamped by Windows to the 2560x1440 monitor: true 4K is untested). One agent reviewed
each configuration's screenshots; a second viewed each reported defect and kept only the real ones: 132 (2 high, 48 med, 82 low).
