# Command line reference

`Albion Atlas 0.16.0 -- Fable: The Lost Chapters maps -> .glb / .obj`

Generated by `tools/gen_cli_reference.py` from `AlbionAtlas --help`; edit `src/main.cpp`'s usage text, not this file.
Every command takes `--install <fable-root>` (default: the Steam / GOG install found on this machine).
Commands that write game files keep a one-time `<file>.atlas-orig` backup and are refused while Fable runs.

```text

usage:
  AlbionAtlas list   [--install <fable-root>]
  AlbionAtlas info   <map|file.lev> [--install <fable-root>]
  AlbionAtlas export <map|file.lev> [--out <file.glb|file.obj>] [options]
  AlbionAtlas new-level <donor> <name> [--at x,y] [--region <host>] [--dedicated] [--no-rebake] [--install <root>]
  AlbionAtlas blank-level <name> [--size WxH] [--at x,y] [--region <host>] [--template <map>] [--theme <slot|name>] [--height <h>] [--install <root>]
      new-level / blank-level: [--own-region [new|<filler region>]] [--merge-into <filler>] [--display <name>] [--no-minimap]
      (own region = a NEW region slot (`new`; complete on a game started after it) or a retail filler slot taken over; baked MINIMAP_<NAME>)
  AlbionAtlas world  [--install <root>]                      every map's box, region and baked origin
  AlbionAtlas world-move <map> <x> <y> [<map> <x> <y> ...] [--install <root>]
      (relocate maps: WLD/BWD placement + STB chunks translated to the new origins, touching neighbours re-baked)
  AlbionAtlas world-owner <map> <region>   |   AlbionAtlas world-sees <region> <map> <0|1>   (region edits; world --regions lists them)
  AlbionAtlas theme-add <png> <NAME> [--donor <ENGINE_THEME>] [--cliff <png>] [--install <root>]
      (a ground theme from your own texture: appended to textures.big + a new ENGINE_THEME in game.bin; paint it from the editor)
  AlbionAtlas textures [filter] [--bank <bank>]              (list textures.big entries: id, size, format, bank)
  AlbionAtlas texture-export <name> <out.png>   |   texture-replace <name> <image>   |   texture-add <name> <image> [--bank B] [--format dxt1|dxt3|argb8888]
  AlbionAtlas entrance <map> [x y [z]]                    (show / set the map's region entrance in FinalAlbion.gtg; z defaults to the ground)
  AlbionAtlas backups   |   AlbionAtlas restore [--forget]      (every .atlas-orig / .atlas-created under the install; restore puts the retail files back)
  AlbionAtlas region-props <region> [--def <REGION_DEF>] [--minimap <MINIMAP_X>] [--display <name>] [--worldmap 0|1]   (a region's def/minimap/name, WLD + BWD)
  AlbionAtlas world-stitch <map> [<map2>] [--feather <cells>|auto] [--dry-run] [--install <root>]
      (average the shared edge heights with every edge-sharing neighbour, or one pair; world-move --stitch does it after a move)

export options:
  --out <path>        output file; .glb (default, self-contained) or .obj (+ .mtl + PNG)
  --install <root>    Fable TLC install dir (default: auto-detect Steam)
  --no-textures       heightmap only (no install needed)
  --foliage           add the baked grass/plants/trees as mesh instances (needs install)
  --things            add the placed objects (fences, walls, rocks, buildings) from the .tng
  --creatures         with --things: include creature meshes in bind pose
  --particles         with --things: static stand-ins for particle emitters (flames, sun beams, lights)
  --no-water          leave out the water surface (lakes, rivers, sea)
  --max-texture <px>  shrink object/plant textures to at most <px> on a side (256 = quarter-size files)
  --layers            also write splat attributes + one PNG per ground theme
  --texels <n>        baked albedo texels per cell edge (default 8)
  --tile <units>      world units per texture repeat (default 8, the engine's)
  --gain <f>          brighten the baked ground texture (1 = raw texels; ~2 looks like in-game)
  --up <y|z>          up axis: y = glTF/Blender/Unreal-friendly (default), z = Fable native
  --world             place the map at its world position (WLD MapX/MapY) so maps line up
  --origin <x,y>      add an explicit offset (Fable units) to every vertex
  --walkable-colors   COLOR_0 vertex colours: white = walkable, red = blocked
  --quiet             only print errors
```
